# Browser evidence

Current captures are generated by `npm run test:browser` in the ignored
`frontend/test-results/` directory and attached to `frontend/playwright-report/`.
CI uploads both as `browser-contract-<run id>` for review on success or failure.

Four representative compositions (List at 1280/390/320px and desktop Grid)
show hierarchy and wrapping. Interaction and geometry coverage runs across
more states without storing a screenshot for each state. A capture is evidence
for visual judgment, not a passing assertion of quality. See the
[design contract](../design/calendar-explorer.md#verification) for the claims
and checks. Inspect only affected compositions for a change.

Historical galleries and platform-specific pixel baselines were retired to
reduce duplicated evidence and PR churn. They remain in
[Git history before this change](https://github.com/JaneJeon/calendars/tree/aabf65c/docs/screenshots).
Do not commit generated captures. Put focused review evidence in the PR's
browser artifact, with the checked result explained in the PR description.
