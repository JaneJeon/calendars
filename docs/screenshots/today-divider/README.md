# Earlier Today divider review captures

These before/after captures record the first implementation of the Today
boundary. They are historical evidence for the change that established one
boundary owner and placed the label between event dates.

The 2026-09-27 spacing review supersedes the old one-rhythm conclusion. The
current model gives same-day event cards a peer gap, gives date groups stronger
separation through the parent List stack, and lets the Today label set its own
height. The current behavior and geometry contract lives in
`docs/design/calendar-explorer.md`; representative current List renders are
reviewed at 1280px, 390px, and 320px.
