# Calendar explorer browser contract

Playwright checks behavior and geometry across the supported viewports. It
covers keyboard and pointer interaction, 320px WebKit touch, popover alignment,
filter rows, focus return, Grid/List exclusivity, List spacing, Today
transitions, document width, and subscription URLs.

The suite does not compare stored screenshots. Three current List renders at
1280px, 390px, and 320px attach to the successful Playwright report for visual
review. The attachments are generated with the report and are not checked-in
image baselines.
